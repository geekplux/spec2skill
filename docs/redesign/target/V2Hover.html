Run it from the command line

Writes the skill to disk and ends with its audit. Works offline, with no key.

$ git clone https://github.com/geekplux/spec2skill $ cd spec2skill && pnpm install $ pnpm cli openapi.yaml --out .claude/skills

How it works

Parse

OpenAPI 3.0 and 3.1, Swagger 2.0 and MCP tool lists become one model, in your browser.

Relate

Outputs that match inputs, nested paths and shared schemas become links, each exact or inferred.

Write and audit

SKILL.md, a tested kit, references, examples, evals and CI, audited before you download.

Check

The map shows every operation and link, so you can see what the skill teaches your agent.
