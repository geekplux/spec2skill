# tasks-api

An agent skill for the Tasks API: read [SKILL.md](SKILL.md) first.

## Install

```sh
unzip tasks-api-skill.zip -d .claude/skills/   # or your agent's skills directory
node .claude/skills/tasks-api/scripts/audit.mjs .claude/skills/tasks-api   # prints "audit passed"
```

Live calls read credentials from `TASKS_API_*` variables (see [references/auth.md](references/auth.md)) and an optional `TASKS_API_BASE_URL`. Examples and the audit never call the API.

## Layout

- `SKILL.md`: the one idea, the workflow and the quality bar; `references/`: one page per resource plus auth, workflows, pagination and errors.
- `kit/`: `operations.json` and the code calls are built from; `examples/`: worked examples (each `examples/*/run.mjs` runs with plain `node`).
- `scripts/`: `audit.mjs` and the regression tests (`node --test scripts/*.test.mjs`); `evals/evals.json`: graded prompts; `ci/github-workflow.yml`: runs all of it.
