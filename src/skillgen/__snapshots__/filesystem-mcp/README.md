# filesystem-mcp

An agent skill for the secure-filesystem-server: read [SKILL.md](SKILL.md) first.

## Install

```sh
mkdir -p .claude/skills && unzip filesystem-mcp-skill.zip -d .claude/skills/   # or your agent's skills directory
node .claude/skills/filesystem-mcp/scripts/audit.mjs .claude/skills/filesystem-mcp   # prints "audit passed"
```

Live calls read the server endpoint from `FILESYSTEM_MCP_URL`. Examples and the audit never call the API.

## Layout

- `SKILL.md`: the one idea, the workflow and the quality bar; `references/`: one page per resource plus auth, workflows, pagination and errors.
- `kit/`: `operations.json` and the code calls are built from; `examples/`: worked examples (each `examples/*/run.mjs` runs with plain `node`).
- `scripts/`: `audit.mjs` and the regression tests (`node --test scripts/*.test.mjs`); `evals/evals.json`: graded prompts; `ci/github-workflow.yml`: runs all of it.
