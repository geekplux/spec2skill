# petstore-api

An agent skill for the Swagger Petstore: read [SKILL.md](SKILL.md) first.

## Install

```sh
mkdir -p .claude/skills && unzip petstore-api-skill.zip -d .claude/skills/   # or your agent's skills directory
node .claude/skills/petstore-api/scripts/audit.mjs .claude/skills/petstore-api   # prints "audit passed"
```

Live calls read credentials from `PETSTORE_API_*` variables (see [references/auth.md](references/auth.md)) and an optional `PETSTORE_API_BASE_URL`. Examples and the audit never call the API.

## Layout

- `SKILL.md`: the one idea, the workflow and the quality bar; `references/`: one page per resource plus auth, workflows, pagination and errors.
- `kit/`: `operations.json` and the code calls are built from; `examples/`: worked examples (each `examples/*/run.mjs` runs with plain `node`).
- `scripts/`: `audit.mjs` and the regression tests (`node --test scripts/*.test.mjs`); `evals/evals.json`: graded prompts; `ci/github-workflow.yml`: runs all of it.
